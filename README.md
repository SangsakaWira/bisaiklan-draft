# bisaiklan-draft

Satu repo untuk semua mockup produk. Setiap produk ada di foldernya sendiri dan tampil di GitHub Pages:
`https://sangsakawira.github.io/bisaiklan-draft/<produk>/`

| Folder | Produk | Sumber |
|---|---|---|
| `balikos/` | Balikos.com, pencarian kos di Bali | `balikos.com/deploy/` |

Semua data di mockup adalah contoh. Jangan masukkan nomor, harga, atau data pribadi asli.

Menambah produk: salin isi `<proyek>/deploy/` ke folder baru, tambahkan tautannya di `index.html` dan tabel ini, lalu commit dan push.
